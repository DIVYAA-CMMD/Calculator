#  Calculator

## Description

A Python-based calculator that performs mathematical operations through a simple menu-driven interface.

## Requirements

- Python 3.x
- VS Code or any text editor (optional)

## Environment Setup

1. Install Python 3.x on your computer.
2. Make sure Python is added to the system PATH.
3. Open the project folder in a terminal.

## Dependencies

This project uses only Python's built-in features and does not require any external libraries or packages.



## Configuration

No additional configuration or setup is required.

## How to Run

1. Open a terminal.
2. Navigate to the folder containing `calculator.py`.
3. Run the following command:


python calculator.py
